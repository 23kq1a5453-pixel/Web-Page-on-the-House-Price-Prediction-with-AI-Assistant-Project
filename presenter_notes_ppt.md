## Slide 2: Problem Statement
Problem: Real-estate pricing is influenced by many factors, and manual estimation can be uncertain and time consuming.

Presenter notes:
- In real estate, price depends on multiple characteristics such as location, size, age, and facilities.
- Buyers and sellers often find it difficult to determine a fair pricing value without proper analysis.
- This project addresses that problem by using data-driven prediction.

## Slide 3: Objectives
- Build a prediction model for house prices

- Present the system in an easy-to-use interface

Presenter notes:
- The main aim is to create an intelligent and practical solution.
- The system should be easy to understand, simple to use, and suitable for demonstration.

## Slide 4: Methodology
- Data collection and feature selection
- Model training using Random Forest Regressor
- Train-test splitting
- Evaluation using R², MAE, and RMSE
- Prediction and dashboard output

Presenter notes:
- I selected the most relevant features such as area, bedrooms, bathrooms, age, distance to city, location score, garage, and garden.
- Random Forest was chosen because it works well with tabular and non-linear data.
- After training, the model was tested to measure performance.

## Slide 5: Algorithm Used
Algorithm: Random Forest Regressor

Presenter notes:
- Random Forest is an ensemble learning method.
- It creates multiple decision trees and combines their results to get a more stable prediction.
- It is suitable for regression problems and handles complex patterns well.
