# House Price Prediction Using Machine Learning

## Executive Summary Slide

Project Objective:
- Develop an intelligent system to estimate house prices using key property attributes.

Problem Addressed:
- Real estate pricing is influenced by multiple factors and is often difficult to estimate manually.

Methodology:
- Collected and processed housing features such as area, bedrooms, bathrooms, age, city distance, location score, garage, and garden.
- Used Random Forest Regressor for prediction.
- Evaluated performance using R² Score, MAE, and RMSE.

Key Result:
- Model achieved strong predictive performance and generated real-time price estimation.

Application:
- Useful for buyers, sellers, investors, and real-estate decision support.

Future Scope:
- Extend using real property datasets, comparison with other algorithms, and web deployment.
