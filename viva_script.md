# Viva Presentation Script

## Introduction
Good morning/afternoon everyone. My project is titled House Price Prediction Using Machine Learning. This project focuses on developing a predictive system that estimates the price of a house based on important property features such as area, bedrooms, bathrooms, age, distance to the city, location score, garage, and garden availability.

## Problem Statement
Real estate pricing is influenced by many variables, and manual estimation is often inconsistent and time-consuming. Buyers, sellers, and investors need a reliable way to understand the approximate value of a property before making decisions. This motivated me to build an intelligent system that can estimate house prices more efficiently and accurately.

## Objectives
The main objective of the project is to create a machine learning model that can learn patterns from housing data and predict prices based on available property attributes. The project also aims to present the result in a clear, user-friendly interface suitable for academic demonstration and evaluation.

## Methodology
I used a dataset containing several housing-related attributes. I selected the key features most relevant to price prediction and trained a Random Forest Regressor model because it performs well on tabular data and handles non-linear relationships effectively. I then split the dataset into training and testing sets to evaluate model performance with standard metrics such as R² score, Mean Absolute Error, and Root Mean Squared Error.

## Model and Output
The system predicts house price based on the input values provided by the user. In the demo, I can adjust the property details and the model generates an estimated price in real time. The output also shows how accurately the model performs, which makes the project more transparent and reliable.

## Why This Project Matters
This project is important because it applies machine learning to a real-world problem. It helps reduce uncertainty in property valuation and shows how data-driven techniques can support decision-making in the real estate sector. It also demonstrates practical understanding of machine learning, data preprocessing, model evaluation, and application design.

## Future Scope
In the future, this project can be extended by using real-world property datasets, comparing multiple algorithms, integrating charts and visual analytics, and deploying the model as a web application for broader use.

## Conclusion
In conclusion, this project demonstrates the practical application of machine learning in predicting house prices. It is simple, effective, and suitable for final-year academic presentations because it combines technical implementation, evaluation, and user-friendly output in one complete system.
