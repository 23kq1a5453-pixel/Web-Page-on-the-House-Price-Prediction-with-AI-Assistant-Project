# House Price Prediction Using Machine Learning

## Slide 1 — Title
House Price Prediction Using Machine Learning
Final Year Project

## Slide 2 — Introduction
- Real estate pricing depends on multiple factors.
- Manual valuation can be uncertain and inconsistent.
- A data-driven solution can improve property assessment.

## Slide 3 — Problem Statement
- Price depends on area, location, age, and facilities.
- Buyers and sellers need reliable price estimates.
- Traditional methods are slow and often inaccurate.

## Slide 4 — Objectives
- Predict house prices using machine learning.
- Analyze important property features.
- Improve valuation accuracy and decision-making.
- Develop a user-friendly showcase application.

## Slide 5 — Scope of the Project
- Residential property price prediction.
- Focus on housing features and location factors.
- Suitable for real estate and academic demonstration.

## Slide 6 — Methodology
- Collect housing data and select features.
- Preprocess and split dataset into train/test sets.
- Train model using Random Forest Regressor.
- Evaluate prediction accuracy using metrics.

## Slide 7 — Algorithm Used
- Random Forest Regressor
- Handles tabular data efficiently.
- Works well with non-linear relationships.
- Produces stable and accurate predictions.

## Slide 8 — Results and Evaluation
- R² Score: measures model fitness.
- MAE: average prediction error.
- RMSE: overall error in the model.
- Results show strong prediction capability.

## Slide 9 — Demo / Live Output
- User enters property details.
- System predicts estimated house price.
- Dashboard displays result clearly and quickly.

## Slide 10 — Conclusion and Future Work
- Project successfully predicts house prices.
- Useful for real-estate valuation and academic demonstration.
- Future scope: real datasets, advanced algorithms, and deployment.

---

Short presenter note:
This project addresses the challenge of uncertain property valuation by using machine learning to estimate house prices based on key housing features. I used a Random Forest Regressor because it performs well on tabular data and handles non-linear relationships. The system was evaluated using R², MAE, and RMSE, and it provides a clear output through an interactive dashboard. The project demonstrates how machine learning can be applied to a real-world problem in the real estate domain and can be expanded further with real datasets and deployment in the future.
